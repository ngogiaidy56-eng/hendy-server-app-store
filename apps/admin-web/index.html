OPERATIONS

Luồng phát hành

LIVE API
01
Chuẩn bị gói phần mềm

Build đúng nền tảng, phiên bản và kiến trúc; lưu mã nguồn cùng log build.

02
Đưa binary lên storage

Dùng R2 hoặc kho HTTPS riêng. Đối với upload API hiện tại, giới hạn trực tiếp là 25 MiB.

03
Đối chiếu SHA-256

Hash phải lấy từ đúng tệp phân phối, không nhập một giá trị minh họa.

04
Xuất bản cho người dùng

Chuyển trạng thái release sang published sau khi đã xác minh gói tải và URL.

Deployment note

UI này không tự tạo binary hay triển khai ứng dụng mới. Hãy tích hợp pipeline build/sign/release của sản phẩm trước khi quảng bá tự động hóa.
